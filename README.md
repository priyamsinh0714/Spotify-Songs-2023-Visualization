# Spotify 2023 Data Visualization and Predictive Analytics  

## Overview  
This project analyzes the "Most Streamed Spotify Songs of 2023" dataset to provide actionable insights for Sony Music's CMO. The project features advanced visualizations created using R/Tableau to support predictive analytics and improve business decision-making.  

## Project Details  
- **Part A: Practical Work**  
  - Created five predictive visualizations to assist in business decisions, such as market trends, song performance, and audience preferences.  
  - Visualizations focus on data-driven insights for Sony Music’s strategic planning.  

- **Part B: Report Writing**  
  - Discussed the **four data analytics processes** for data governance and the features of R/Tableau aligning with governance principles.  
  - Addressed ethical aspects of data visualization and applied three key ethics values.
  - Provided detailed justifications for predictive insights derived from Part A visualizations.

## Key Features  
1. **Decision-Making Visualizations:**  
   - Created five predictive visualizations to analyze trends, song performance, and audience demographics.  
   - Examples: Genre popularity trends, global song performance heatmap, artist comparison, and audience segmentation.

2. **Ethical Considerations:**  
   - Maintained ethics in data visualization by ensuring accuracy, avoiding bias, and maintaining audience trust.  
   - Followed data governance principles for integrity and accountability.  

3. **Business Recommendations:**  
   - Provided actionable insights for Sony Music, such as identifying rising artists, forecasting genre trends, and optimizing marketing strategies.
